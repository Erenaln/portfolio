# 💰 Java Compound Interest Calculator

**Version:** v1.0 (Console Edition)

A console-based financial application that calculates the future value of an investment using the compound interest formula ($A = P(1 + \frac{r}{n})^{nt}$). This tool simulates real-world banking calculations to predict long-term investment growth.

### ⚙️ Core Features
* **Financial Mathematics:** Utilizes `Math.pow()` to handle the complex exponentiation required for the compound interest formula.
* **Dynamic Inputs:** Captures the principal deposit amount, annual interest rate, compounding periods per year, and total maturity (in years) via `java.util.Scanner`.
* **Precision Handling:** Uses `double` data types to accurately process fractional percentages and financial decimals without precision loss.

### 🚀 Future Plans
* **Graphical User Interface (GUI):** Upgrading from a console-based system to a fully visual desktop application.
* **Output Formatting:** Implementing string formatting to display the final currency with exact decimal precision.
